= Camel JBang Launcher

*Available as of Camel 4.13*

This module provides a self-contained executable JAR that includes all dependencies required to run Camel JBang without the need for the JBang two-step process.

The launcher uses Spring Boot's loader tools to create a self-executing JAR with a nested structure, similar to Spring Boot's executable JARs. This provides better performance and avoids classpath conflicts compared to traditional fat JARs.

== Downloading

You can download the `camel-launcher` JAR from https://repo1.maven.org/maven2/org/apache/camel/camel-launcher/[Maven Central].

== Using the fat-jar directly

Then you can run the JAR using standard Java as follows:

[source,bash]
----
java -jar camel-launcher-<version>.jar [command] [options]
----

For example:

[source,bash]
----
java -jar camel-launcher-<version>.jar version
java -jar camel-launcher-<version>.jar run hello.java
----

== Using the distribution (recommended)

Extract the distribution archive:

[source,bash]
----
unzip camel-launcher-<version>-bin.zip
# or
tar -xzf camel-launcher-<version>-bin.tar.gz
----

And then use the provided scripts:

[source,bash]
----
# On Unix/Linux
./bin/camel.sh [command] [options]

# On Windows
bin\camel.bat [command] [options]
----

== Benefits of using Camel Launcher

- No need for JBang installation
- Single executable JAR with all dependencies included
- Faster startup time (no dependency resolution step, on-demand class loading)
- Better memory usage (only loads classes that are actually used)
- Avoids classpath conflicts (dependencies kept as separate JARs)
- Each self-executing JAR is its own release, avoiding version complexity
- Can still be used with JBang if preferred

== Launcher Limitations

The camel-launcher is a self-contained JAR for a specific Camel version. Some features that require JBang are not available or have limitations:

=== Not Supported in Launcher Mode

The following features require JBang and are **not supported** when using camel-launcher without JBang installed:

* **`--camel-version` option**: The launcher is built for a specific Camel version and cannot switch to a different version at runtime.
  - To use a different Camel version, download the corresponding camel-launcher JAR for that version.
  - Alternatively, install JBang and use the `camel` command with the `--camel-version` option.

* **`--runtime=quarkus` or `--runtime=spring-boot` options**: These runtimes require JBang for project generation and execution.
  - If you need to use these runtimes with the launcher, install JBang from https://www.jbang.dev/
  - Use `--runtime=camel-main` (the default) for launcher-only usage.

=== Background Mode

Background mode (`--background`) works in launcher mode but requires the launcher JAR to be accessible:

[source,bash]
----
# This works if the launcher JAR is in the classpath
java -jar camel-launcher-<version>.jar run myroute.yaml --background
----

=== Using Different Camel Versions

The recommended approach for using different Camel versions is to download the appropriate launcher for each version:

[source,bash]
----
# Download launcher for Camel 4.13.0
wget https://repo1.maven.org/maven2/org/apache/camel/camel-launcher/4.13.0/camel-launcher-4.13.0.jar

# Download launcher for Camel 4.14.0
wget https://repo1.maven.org/maven2/org/apache/camel/camel-launcher/4.14.0/camel-launcher-4.14.0.jar

# Run with specific version
java -jar camel-launcher-4.13.0.jar run myroute.yaml
java -jar camel-launcher-4.14.0.jar run myroute.yaml
----

Alternatively, install JBang for full flexibility:

[source,bash]
----
# Install JBang
curl -Ls https://sh.jbang.dev | bash -s - app setup

# Use any Camel version
camel run myroute.yaml --camel-version=4.13.0
camel run myroute.yaml --camel-version=4.14.0
----
