# Apache Camel PR Review Loop

## Configuration

| Setting | Value |
|---------|-------|
| Pattern | pr-review-loop |
| Cadence | precondition-based (ETag + check-pr-work.sh) |
| Level | L2 (assisted) |
| Max PRs per run | 5 |
| State branch | pr-review-loop-state |

## Skills Used

- `forgebot-review-loop` — main review orchestrator
- `forgebot-loop-core` — circuit breaker, budget, constraints
- `oss-review` — review-pr.md guideline for actual review logic

## How to Run

```
/loop --precondition "~/.claude/scripts/check-pr-work.sh" /forgebot-review-loop
```

## Notes

- Self-authored PRs (by gnodet) are reviewed with COMMENT event (cannot APPROVE own PRs)
- Reviews from gnodet must be addressed by PR authors but do NOT count as human approvals
- Exclude draft PRs and PRs with titles starting with `[DO NOT MERGE]`
- Attribution: "_Claude Code review on behalf of @gnodet_"
- AI disclaimer: "_This review was generated by an AI agent and may contain inaccuracies._"
